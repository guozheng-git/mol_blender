# Blender presets

Generated by `scripts/build_plugin.py` from the renderer's built-in catalog. Pass the id to `studio.py render --preset ID`.

General presets work on any structure. Chain-specific presets select chain IDs from their example structure; on other structures those selections fall back to the preset's base colors, so check the result or prefer a general preset.
